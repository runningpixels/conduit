Conduit update channels

This branch is the static host for Conduit's Tauri updater manifests. It is not the project site.

  • /stable/manifest.json — stable channel
  • /beta/manifest.json — beta channel (prerelease and nightly tags)

A release workflow generates the manifest for the channel its tag routes to; promoting beta to stable republishes the same payload under the stable path. See docs/release/promotion.md in the repository.
